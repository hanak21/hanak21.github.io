Assignment 1: Count the Fireflies

So many fireflies and so many colours.

Notes

This is a quick activity to test your visual perception by counting some colourful and energetic fireflies. The number of fireflies is calculated with an original function called function fireflyAnswer. Press A to see the answer, but don’t forget to check your cursor first for any bright, flying visitors following after you. Link to repo.
